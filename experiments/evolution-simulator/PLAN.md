# Evolution Simulator walkthrough plan

[Open Evolution Simulator in Project Lab](https://stiwarilbj.github.io/Shantanu_Tiwari/experiments/evolution-simulator/) · [Visual and interaction design](VISUAL-DESIGN.md)

Start with one blob looking for food. Follow its choices into the population charts, change one setting, then watch two worlds to see what happened. Finish with an experiment the visitor can run. Use the reference for the sequence, mechanics, camera choices, and teaching interactions. Draw the field, blobs, icons, and illustrations in Project Lab’s own style and keep its shared navbar. [MinuteLabs walkthrough](https://www.youtube.com/watch?v=6nMo8T3T0L4)

Place energy, credits, and refuge status alongside it as separate live state. Make the readout’s scale and cohort explicit. Center the selected day when it changes by keyboard or chart link and keep the active trait legend visible. The reference ties each ribbon item to its generation number and inline trait glyph. Use the playback behavior specified below for both guided and ordinary replay. [World player](src/components/World.vue), [Generation ribbon](src/components/Ribbon.vue), [Reference ribbon](https://github.com/minutelabsio/evolution-simulator/blob/3b99f358b70a608f5fb3e34fe8f410ba85aec7f3/src/components/flower-timeline.vue)

## 4. Model and architecture

The launch source uses a generation-addressed Vue shell, separate worker requests to initialize, advance, compute statistics, and fetch a generation, a Rust/WebAssembly engine, and a static base path. The store loads a generation for playback as longer runs continue to prepare. The renderer projects overlays onto the active camera and the player separates generation selection, playthrough, speed, and scrubbing. Project Lab already has corresponding boundaries in Vue and Vite, a seeded JavaScript worker, generation checkpoints, and Three.js with a Canvas fallback. Reuse them for the walkthrough. [Launch routes](https://github.com/minutelabsio/evolution-simulator/blob/3b99f358b70a608f5fb3e34fe8f410ba85aec7f3/src/router/index.js), [Launch worker](https://github.com/minutelabsio/evolution-simulator/blob/3b99f358b70a608f5fb3e34fe8f410ba85aec7f3/src/workers/simulation.js), [Launch store](https://github.com/minutelabsio/evolution-simulator/blob/3b99f358b70a608f5fb3e34fe8f410ba85aec7f3/src/store/simulation.js), [Launch player](https://github.com/minutelabsio/evolution-simulator/blob/3b99f358b70a608f5fb3e34fe8f410ba85aec7f3/src/components/view-screen.vue), [Launch build](https://github.com/minutelabsio/evolution-simulator/blob/3b99f358b70a608f5fb3e34fe8f410ba85aec7f3/vue.config.js)
