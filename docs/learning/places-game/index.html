Place Naming Game

Test your geography knowledge by naming as many places as you can!

Game Rules

  • Pick a 1–5 minute time limit and any letter or country filters. Select Load places if prompted, then select Start Game.
  • In the default Place and Country mode, enter both names with a comma, like “Paris, France”. Spaces around the comma are fine.
  • In Place Only mode, enter a place name that matches your filters.
  • Each correct answer gets one point. A name can be one letter off or have two neighboring letters swapped.
  • Search by first or last letter, country, or name length. Separate terms with commas. Include checks for every term in the place or country, and Don't Include skips any match.
  • Display Places shows eight random examples using your filters. Select Pause to take a break.
