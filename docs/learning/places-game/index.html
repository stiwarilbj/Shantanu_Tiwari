Place Naming Game

Test your geography knowledge by naming as many places as you can!

Game Rules

  • Pick a 1–5 minute time limit or Untimed practice, then set any letter or country filters. Select Load places if prompted, then select Start Game. In practice, select Finish Practice when you're ready to review your guesses.
  • In the default Place and Country mode, enter both names with a comma, like “Paris, France”. Spaces around the comma are fine.
  • In Place Only mode, enter a place name that matches your filters.
  • Each correct answer earns one point. Standard allows one typo or swapped neighboring letters per name. Strict requires exact spelling, with any capitalization. Relaxed also accepts missing accents and familiar country names like USA, UK, and Czechia. If more than one place matches, try the exact spelling or add the country.
  • Search by first or last letter, country, or name length. Separate terms with commas. Include checks for every term in the place or country, and Don't Include skips any match.
  • Display Places shows up to eight examples using your filters. In Preferences, switch to Clues only for a hint without the name, or After the round to unlock Search and examples when you finish.
  • To take a break, select Pause, then Resume Game when you're ready. Use Preferences to choose what happens when you switch away.
